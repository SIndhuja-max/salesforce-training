# 🚀 Salesforce Training 

## Overview

This repository documents my complete learning journey through the Salesforce Summer Program, covering Salesforce Administration, Development, Automation, DevOps, Agentforce AI, and Enterprise Application Development.

The program combined hands-on exercises, real-world scenarios, mini-projects, Lightning Web Component development, Apex programming, Flow automation, and a capstone College Management System project.

Throughout this training, I gained practical experience in building scalable Salesforce applications while following industry-standard development and deployment practices.
