# Salesforce-training: Day 02-platform basics

## 📌 What is Salesforce Platform?

Salesforce Platform is a cloud-based platform used to build CRM applications, automate business processes, manage customer relationships, and develop scalable business solutions.

---

# 📌 Core Concepts

## App
An App is a collection of related tools, objects, tabs, and functionalities designed for a specific business process.

### Example:
College Management App

---

## Object
An Object stores data in Salesforce similar to a database table.

### Example:
Student Object stores:
- Student Name
- Roll Number
- Department

Each student entry is called a record.

---

## Tab
A Tab is used to access objects and features through the Salesforce user interface.

### Example:
Clicking the Students tab opens Student records.

---

# 📌 CRM Concepts Inside Salesforce

Salesforce stores CRM concepts using objects inside apps.

- Account Object stores company/customer information.
- Contact Object stores person details.
- Opportunity Object stores potential sales deals.

These objects are grouped inside apps where users interact using tabs and records.

---

# 📌 Configuration vs Coding

## Configuration (No Code)

Used when requirements can be solved using Salesforce tools without programming.

### Examples:
- Validation Rules
- Flow Automation

---

## Coding (Apex)

Used for advanced customization and complex business logic.

### Examples:
- API Integrations
- Advanced automation

---

# 📌 Multi-Tenant Architecture

Multi-tenant architecture means multiple companies use the same Salesforce infrastructure securely while keeping their data isolated.

It is similar to multiple families living in the same apartment building with separate rooms and privacy.
