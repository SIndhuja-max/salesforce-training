# Doubts and Questions

## 1. What is the difference between an App and an Object?
An App is a collection of related tools and objects, while an Object stores specific data.

---

## 2. Why does Salesforce prefer configuration before coding?
Configuration is faster, easier to maintain, and requires less development effort.

---

## 3. When should developers use Apex?
Apex should be used when complex business logic or integrations cannot be handled using configuration tools.

---

## 4. What is multi-tenant architecture?
It is a cloud architecture where multiple organizations share the same infrastructure securely.

---

## 5. How do APIs help Salesforce?
APIs allow Salesforce to communicate and exchange data with external systems.

---

## 6. How does Salesforce allow developers to extend functionality?
Salesforce allows developers to extend functionality using Apex, Lightning Components, APIs, Flows, and custom applications built on the Salesforce Platform.

---

## 7. How does development happen in Salesforce?
Development in Salesforce happens through two approaches:
- Configuration using no-code tools like Flows, Validation Rules, and Page Layouts
- Coding using Apex, APIs, and Lightning Components for advanced customization

---

## 8. Difference between Configuration and Coding

### Configuration
- No-code approach
- Faster implementation
- Easier maintenance
- Uses built-in Salesforce tools

### Coding
- Uses Apex and development frameworks
- Handles complex business logic
- Provides advanced customization
- Used when configuration is insufficient
