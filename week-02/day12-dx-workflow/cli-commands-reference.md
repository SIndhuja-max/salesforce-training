# Salesforce CLI Commands Reference

## Login to Org

```bash
sf org login web
```

Purpose:
Authenticate Salesforce Org.

---

## View Connected Orgs

```bash
sf org list
```

Purpose:
Display authorized Salesforce organizations.

---

## Create Salesforce Project

```bash
sf project generate
```

Purpose:
Generate a new Salesforce DX project.

---

## Deploy Source

```bash
sf project deploy start
```

Purpose:
Deploy local metadata to Salesforce.

---

## Retrieve Metadata

```bash
sf project retrieve start
```

Purpose:
Retrieve metadata from Salesforce org.

---

## Run Apex Tests

```bash
sf apex run test
```

Purpose:
Execute Apex test classes.

---

## Open Org

```bash
sf org open
```

Purpose:
Launch Salesforce org in browser.

---

## Logout Org

```bash
sf org logout
```

Purpose:
Disconnect authorized org.
