# Day 12 – Revision Questions and Answers

## 1. Why do enterprise teams use version control?

Enterprise teams use version control to track changes made to source code over time. It allows developers to collaborate efficiently, maintain a history of modifications, recover previous versions when necessary, and prevent accidental loss of work. Version control systems such as Git and GitHub improve project organization and software quality.

---

## 2. Why is deployment workflow important?

Deployment workflow is important because it provides a structured process for moving changes from development environments to production environments. It helps ensure that software is properly tested, reviewed, and validated before release, reducing the risk of introducing defects into live systems.

---

## 3. What problems happen without collaboration tools?

Without collaboration tools, teams may experience:

- Overwritten code
- Lost changes
- Duplicate work
- Poor communication
- Difficult conflict resolution
- Lack of project visibility
- Increased deployment failures

Collaboration tools help developers work together efficiently and maintain project consistency.

---

## 4. Why is Salesforce DX important?

Salesforce DX is important because it introduces a modern, source-driven development model for Salesforce projects. It enables better collaboration, version control integration, automated deployments, and improved developer productivity. Salesforce DX aligns Salesforce development with industry-standard software engineering practices.

---

## 5. Why do developers prefer CLI tools?

Developers prefer CLI tools because they are faster, more efficient, and easier to automate than performing repetitive actions through graphical interfaces. CLI tools enable developers to deploy code, run tests, manage environments, and automate workflows using simple commands.

---

## 6. Why do enterprise systems require rollback capability?

Enterprise systems require rollback capability so that organizations can quickly restore a previous stable version if a deployment introduces errors or unexpected issues. Rollback minimizes downtime, reduces business impact, and improves system reliability.

---

## 7. Why should teams separate development and production?

Teams should separate development and production environments to protect live business operations and customer data. Development environments allow testing and experimentation without affecting end users, while production environments remain stable and secure.

---

## 8. Why is source-driven development useful?

Source-driven development is useful because it treats source code as the primary source of truth. This approach improves version control, collaboration, deployment consistency, and project maintainability. It also makes it easier to track changes and manage software releases.

---

## 9. Why is collaboration difficult in large projects?

Collaboration is difficult in large projects because multiple developers may work on the same files, features, or components simultaneously. Without proper processes and tools, teams can encounter conflicts, communication issues, duplicated efforts, and integration challenges. Structured workflows help manage these complexities.

---

## 10. Why is engineering workflow important?

Engineering workflow is important because it provides a systematic approach to software development. It ensures proper planning, collaboration, testing, deployment, monitoring, and maintenance. A well-defined workflow improves software quality, team productivity, and project success.

---
