# Real-World Salesforce Engineering Scenarios

## Scenario 1

Problem:

A deployment introduced a bug affecting customer accounts.

Solution:

GitHub rollback restored the previous stable version within minutes.

Learning:

Version control protects production systems.

---

## Scenario 2

Problem:

Two developers modified the same Apex class.

Solution:

GitHub merge conflict tools identified and resolved differences.

Learning:

Collaboration tools prevent code loss.

---

## Scenario 3

Problem:

An organization deployed directly to production without testing.

Result:

Business users experienced system failures.

Learning:

Always deploy through testing environments first.

---

## Scenario 4

Problem:

A team manually deployed metadata every week.

Solution:

Salesforce CLI automated deployments.

Learning:

Automation improves productivity and consistency.
