# Salesforce Summer Program 

## Week Overview

This week focused on advanced Salesforce development concepts including Lightning Web Components (LWC), component communication, project development, testing, Salesforce DX, DevOps practices, CI/CD pipelines, Flow Builder, and Enterprise Governance.

The goal of the week was to move from basic component development to enterprise-level application design, deployment automation, and controlled business workflows.

### Branching Logic Example

Attendance Monitoring Workflow:

* Attendance < 50% → Admin Escalation
* Attendance < 60% → Parent Notification
* Attendance < 75% → Warning Email
* Attendance ≥ 75% → No Action
