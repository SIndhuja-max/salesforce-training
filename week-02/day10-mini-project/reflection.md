# Project Reflection

## Overview

The College Management System project provided practical experience in building a complete Salesforce application from scratch.

The project combined multiple Salesforce technologies including custom objects, relationships, validation rules, formula fields, flows, Apex, triggers, and Lightning Web Components.

---

# Challenges Faced

## Data Modeling

Initially, designing relationships between Student, Faculty, Department, Course, and Registration objects required careful planning.

---

## Formula Fields

Understanding Salesforce percentage values required special attention because percentages are stored internally as decimal values.

Example:

75% = 0.75

---

## Flow Automation

Building Record-Triggered Flows required understanding how Salesforce executes automation when records are created.

---

## Apex Development

Developing Apex classes and triggers introduced concepts such as:

- SOQL Queries
- Trigger Context Variables
- Event Processing

---

## Lightning Web Components

Integrating Apex with Lightning Web Components was one of the most valuable learning experiences.

---

Through this project I learned:

- Salesforce Data Modeling
