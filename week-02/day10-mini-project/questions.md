# Revision Questions and Answers

## 1. What is Salesforce CRM?

Salesforce CRM is a cloud-based platform used for customer relationship management, application development, automation, and business process management.

---

## 2. What is a Custom Object?

A Custom Object is a user-created database table used to store specific business information.

Example:

- Student
- Faculty
- Course

---

## 3. What is a Lookup Relationship?

A Lookup Relationship connects two objects without creating a mandatory parent-child dependency.

Example:

Student → Department

---

## 4. What is a Formula Field?

A Formula Field automatically calculates values using a formula.

Example:

Remaining Seats = Total Seats - Filled Seats

---

## 5. What is a Validation Rule?

A Validation Rule prevents invalid data from being saved.

Example:

Attendance cannot exceed 100%.

---

## 6. What is Salesforce Flow?

Salesforce Flow is an automation tool used to automate business processes without coding.

---

## 7. What is Apex?

Apex is Salesforce's object-oriented programming language used to implement custom business logic.

---

## 8. What is a Trigger?

A Trigger automatically executes Apex code when records are inserted, updated, deleted, or restored.

---

## 9. What is SOQL?

SOQL (Salesforce Object Query Language) is used to retrieve records from Salesforce.

Example:

```sql
SELECT Name FROM Student__c
```

---

## 10. What is Lightning Web Component?

Lightning Web Component (LWC) is Salesforce's modern UI framework used for building reusable user interfaces.

---

## 11. What is @AuraEnabled?

@AuraEnabled allows Apex methods to be called from Lightning Components and Lightning Web Components.

---

## 12. What is Record-Triggered Flow?

A Record-Triggered Flow executes automatically when a record is created or updated.

---

## 13. What are the benefits of Formula Fields?

- Automatic calculations
- Reduced manual effort
- Improved accuracy

---

## 14. What are the benefits of Validation Rules?

- Data integrity
- Improved quality
- Reduced user errors

---

## 15. What did you learn from this project?

I learned how Salesforce combines data modeling, automation, Apex programming, and Lightning Web Components to create complete enterprise applications.
