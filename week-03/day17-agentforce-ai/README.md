# What is Agentforce?

Agentforce is Salesforce's AI platform that allows organizations to create intelligent AI agents capable of:

- Understanding user requests
- Reasoning about business context
- Accessing enterprise data
- Triggering Flows
- Executing Apex actions
- Performing automated tasks

Unlike traditional chatbots, Agentforce agents can perform actions instead of only answering questions.

---

# What is an AI Agent?

An AI Agent is a software system that can:

1. Receive a goal or request
2. Analyze the request
3. Make decisions
4. Access tools and data
5. Perform actions
6. Return results

Example:

Student:
"Show my attendance percentage."

AI Agent:

- Retrieves attendance data
- Calculates percentage
- Generates response
- Displays result

AI agents can automate:

- Service requests

# Importance of Governance

AI systems must be controlled carefully.

Organizations should implement:

- Permission controls
- Validation rules
- Human oversight
- Monitoring
- Approval mechanisms
- Security policies

Without governance, AI systems may create business risks.
